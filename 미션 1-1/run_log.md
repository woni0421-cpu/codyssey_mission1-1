# 실행 로그 (Run Log)

## [작업 기록]

- 과업 정의: 수학학원 강사의 학부모용 일일 학습보고 문자메시지 자동 생성으로 과업을 정하고, 타깃 사용자와 입력 및 출력 규격을 정의함.

- 모델 세 종 비교: GPT, Gemini, Claude에 동일한 프롬프트를 입력하고 응답 결과를 비교함.

- 비교 기준 확정: 출력 규격 준수, 필수 입력 정보 누락, 과업 이해도 및 페르소나 반영, 운영 효율성의 네 가지 기준으로 평가함.

- 프롬프트 v1: 고정된 출력 양식과 작성 규칙을 설정하고, 반복적으로 사용할 수 있는 입력 템플릿을 작성함.

- 프롬프트 v2: 문자 분량을 500자 미만으로 축소하고, 자연스러운 문체와 항목 간 내용 분리, 허위 정보 생성 방지 및 최신 출력 조건 준수를 위한 규칙을 강화함.

## 다중 턴 대화 및 환각 검증

- 실행 일자: 2026.11.25
- 사용 모델: GPT-6
- 적용 프롬프트: 기본 v1 + Few-shot 예시 3건 + 단계별 작업 절차
- 대화 수: 14턴 (User 7회, AI 7회)

### Turn 1 — User:

```text
너는 수학학원 수석 학습 관리자다. 선생님이 준 입력값으로 학부모용 문자 한 통을 아래 양식 그대로 작성하라.

■ 출결 / ■ 일일테스트 / ■ 학습 내용 / ■ 학습 태도 / ■ 숙제 현황 / ■ 피드백

- 출결, 테스트 점수, 학습 단원은 입력값을 그대로 쓴다. 점수에 평가 문구를 붙이지 않는다.
- 학습 태도와 피드백은 메모의 뉘앙스를 관찰 가능한 구체적 행동으로 풀어 쓴다. 피드백은 "관찰한 사실 → 의미 → 선생님과 가정이 할 구체적 행동" 순서로 쓴다.
- 부정적 내용은 비난 없이 "상황 + 개선 방향"으로 쓴다.
- 입력이 없는 항목은 지어내지 말고 생략하거나 한 줄로 되묻는다.
- 마크다운 없이 일반 텍스트로, 600~800자 안에서 문자 본문만 출력한다.

## 단계별 작업 절차

문자메시지를 작성할 때 다음 절차를 순서대로 수행하라.

1. 입력된 학생 정보, 수치, 학습 내용, 관찰 사실을 확인한다.
2. 입력된 사실, 실제 수행한 지도, 향후 학습 과제, AI가 제안하는 개선 방법을 구분한다.

5. 지정된 양식에 따라 문자메시지를 작성한다.
6. 출력 전 입력값과의 일치 여부, 확인되지 않은 사실이나 계획의 추가 여부, 항목 간 내용 중복 여부를 검토한다.
```
