# 미해결 기록

## 미해결 1. 학생별 맞춤형 일일테스트 자동 생성

### 과업 정의
학생의 이전 성취도와 수업 진도에 따라 매 수업마다 세 문항으로 구성된 일일테스트를 자동 생성하고, 성취도에 따라 복습 문항과 난이도를 조절하는 과업이다.

### 시도한 프롬프트 원문

```text
그래 그럼 내가 지금까지 정한 것들 쭉 적어볼 테니까 이런 식으로 적는 게 맞는지 아닌지 확인해줘.
매 수업마다 학생의 수준과 진도를 고려하는 수학 선생님이라는 페르소나를 기반으로 매 수업마다 일일테스트를 만드는 과업을 반복해야 돼. 타겟 사용자는 초,중,고등학생들이며 학생들이 지난 시간 배운 내용을 잘 익혔는지 확인하는 목적이야. 지난 수업의 주제, 학생의 이전 성취도 두 개를 기반으로 총 세 문제가 나갈 거고, 한 문제당 1점씩 3점 만점에 몇 점인지에 따라 유동적으로 난이도를 계속 조절해서 테스트를 출제할 거야. 기본적으로는 쉬움+보통+어려움 한 문제씩 세 문제 구성인데, 0,1점의 학생 경우에는 해당 단원 문제가 다음 테스트에도 꼭 하나 들어가게끔 해줘. 예를 들어 1단원 테스트에서 0,1점 맞은 학생이라면 2단원 테스트 세 문항에 어려운 거 하나 빼고, 1단원 문제 하나+2단원 쉬운거 하나+2단원 보통 하나 이런 식으로. 2,3점 학생들은 2단원 테스트 문항도 1단원 굳이 또 넣을 필요 없이 2단원 문제들로만 구성. 각 문제 데이터베이스에는 문제 단원 번호, 단원명, 난이도, 문제, 정답, 해설까지 한 세트로 포함되어있어야 해.
```

### 추가 시도
외부 서버에서 문제를 가져오는 방식의 실현 가능성을 AI에게 추가로 질문하였다. AI는 데이터 직접 입력, 함수 호출, RAG 등의 대안을 제시하였으나 외부 서버 연동은 완료하지 못하였다. 함수 호출이나 RAG를 실제 구현한 것은 아니다.

### 받은 결과
문항 구성 규칙과 데이터 구조를 구상하였으나, 외부 문제 데이터를 자동으로 가져오는 기능은 구현하지 못했다.

### 막힌 이유
문제를 외부 서버에서 가져올 수가 없어서 문제 데이터베이스들을 하나하나 내가 입력해야하는 게 너무 수고로워서 과업 선정을 다른 것으로 바꿨다.

## 미해결 2. 정보 전달력과 자연스러운 문체를 동시에 충족하는 학습보고 생성

### 과업 정의
500자 미만의 고정 양식 안에서 학생의 학습 상태와 개선 방향을 자연스럽고 밀도 있게 전달하는 학부모용 일일 학습보고를 생성하는 과업이다.

### 개선 과정
기존 v1에서 장황한 설명과 내용 중복이 나타나 Few-shot 및 단계적 작업 절차를 적용하였다. 이후 v2에서 분량과 문체, 항목 간 중복 관련 규칙을 강화하였다. 마지막으로 자연스러운 교사 문체를 강조하는 추가 프롬프트를 실행하였다. v1과 v2 전문은 시스템 설계 문서에 수록되어 있다.

### 추가로 시도한 프롬프트 원문

```text
기존 학습보고 양식과 사실 정확성, 500자 미만 조건을 유지하면서 문체를 개선해 줘.

실제 수학학원 선생님이 학생을 직접 지도한 후 학부모에게 작성하는 문자처럼 자연스럽고 따뜻하게 작성해 줘.

정형화된 보고서 문체와 기계적인 표현을 지양하고, 학생의 개별적인 특성이 드러나도록 작성해 줘. 단, 입력에 없는 관찰 사실은 추가하지 마.

이전에 입력한 민준 학생의 학습보고를 다시 작성해 줘.
```

### 받은 결과 원문

```text
■ 출결
출석

■ 일일테스트
8/10

■ 학습 내용
일차방정식의 활용

■ 학습 태도
문제에 맞게 식을 잘 세우는 편이지만, 문제의 조건을 조금 급하게 읽는 모습이 있었습니다.

■ 숙제 현황
일부 완료, 3문제 미풀이

■ 피드백
이전보다 계산이 한층 안정적이어서 좋았습니다. 풀이를 시작하기 전에 주어진 조건과 구해야 할 값을 차근차근 정리하는 습관을 들이면 더욱 정확하게 풀 수 있을 것 같습니다. 다음 수업 전까지 오답 2문제를 다시 풀고, 문제에 주어진 조건도 표시해 오도록 합니다.
```

### 막힌 이유 
핵심 입력 정보와 출력 양식은 유지되었으나, 문체를 부드럽게 개선하는 과정에서 완곡한 표현이 늘어나 오히려 신뢰도가 떨어지고 불필요한 말들이 많아 정보량이 줄어든 느낌이었다. 이번 미션에서 만족할 만한 문체와 정보 전달력의 균형을 맞추기 힘들다고 판단하였다.
